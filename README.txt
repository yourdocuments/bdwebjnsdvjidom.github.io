WEBSITESDEAL PREMIUM MARKETPLACE — FRONT-END DEMO
=================================================

Files
- index.html      Public marketplace, Bengali default, EN switch, dark/light theme, search, category filters, website cards, subscription plans.
- admin.html      Admin Studio, banner text editor, website add/edit/delete, JSON export.
- dashboard.html  Dashboard overview and subscription-plan UI.
- website.html    Simple website detail / preview page.

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Open admin.html to manage website listings and banner text.
4. Changes are saved in this browser using localStorage. Use the same browser/profile to see the edits on index.html and dashboard.html.

IMPORTANT LIMITATIONS
This is a static front-end starter/demo. It does not include secure authentication, a shared online database, real payment processing, subscription billing, customer accounts, file uploads, or cross-device publishing. localStorage is browser-specific and must not be treated as secure storage.
For production, connect a backend/database, secure role-based authentication, image storage, order management and a payment gateway. Admin/super-admin roles are represented as future architecture, not enforced secure login in this demo.
